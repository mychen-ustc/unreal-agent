# GDD · 垂直切片（Vertical Slice）——《废海灯语》/《TidalLight》·「沉塔-灯塔」

> 阶段：立项采纳后的首个可执行策划交付（用于指导预生产/生产/验证分工）
> 源概念：[docs/concepts/tidal-light.md](./../concepts/tidal-light.md)（ACTIVE run `run-20260905-084422-da58db69`）
> 定位：不是全量参考游戏，而是把「光=唯一交互语法」的可证伪垂直切片做成立项验证用途。

---

## 0. 一句话

无文字教学下第 1 小时，玩家自主完成「沉塔-灯塔」一段（3 场强制影带怪战斗 + 1 个光闸门谜题），点亮首座灯塔并解锁下一航道；失败率 ≤30% 且不依赖显式 UI/引导 —— 以此证明控光语言成立、立项继续。

## 1. 范围（In scope / Out）

**In**
- 单场景「沉塔-灯塔」区块：一条 8–12 分钟可玩路径（spawn→约3战斗→光闸门→塔点→解锁镜头）。
- 一只核心兵种影带怪；控光攻/盾/导航的基本规则块；光闸门谜题一个；灯之教学以环境引导呈现。
- 核心数值初稿（光资源池/潮汐时间轴/影带怪生命与光影响）。
- UI 仅“无文字/无显式引导”的最小反馈（血/光槽为图标或自然视觉）。
- 通过冒烟进入真 UE 可进入关卡。

**Out**
- 多场景/开放地图/联网/手柄/本地化/多难度/后续机制（潮汐高级解谜/塔网络传送）等——留 P1+。
- 不作为商业化发布，仅验证载体。

## 2. First-hour 验收（本切片的 exit criteria 与判负 → y/n continue）

| 指标 | 验收 | 判负阈值 |
|---|---|---|
| 通关主线 | 新玩家自主完成 3 战斗+1 光闸门→点亮→解锁镜头 | 未能（首次尝试） |
| 教学自明 | 无文字教学/显式 UI 引导，靠“看懂光”学会 | 需 UI/文字教学才能完成 |
| 失败率 | ≤ 30% | \> 30% |
| 手感/卡点 | 冒烟可达所有 waypoint且无明显 blockers | 冒烟 blocked 或断层 |

合成裁决（供 E3/E6 + qa_smoke）：以上全绿 → “控光语言成立”→ 继续；否则进 PIVOT 回退。

## 3. 可玩内容骨架（按 path 节拍）

1. **spawn（灯塔层）** 2 分钟教学区：无文字，用唯一光域让玩家在无人区完成一次“引怪入光”）→ 首场引导战斗，验证 moving/mir/block 基础。
2. **走廊战斗**（场1：1–2 影带怪）→ 学格光影。
3. **光闸门**（谜题）一个：需要把 2 个火种用光引导点亮两边源 → 开门，含一次小失败反馈（光暗下怪涌）。
4. **暗巷冲突**（场2：3 影带逼近，考验拖入光域制造处决）。
5. **崖顶塔战**（场3 + 解除 3 个光楔）→ 塔座旋梯。
6. **点塔收束**：爬上塔灯台把主灯点燃 → 触发潮汐：海面“退潮”→ 露出新航道 → 镜头拉远给解锁感，段结束（UI 无文字，只给自然光反馈）。

节拍式路径：快-慢-快-压力-释压（可与 level_designer 产出动线/pacing 基准对齐）。

## 5. 上线路径 & 提交节奏

- 里程碑 M0 设定→M1 灰盒可进入→M2 控光玩法骨架进 PIE→M3 全段可跑→M4 一次真实新玩家无干预观察（记录行为与卡点）。
- 对每 Step 及时 `schema_check` 一致、`pytest tests` 绿、真引擎 tool 逐步冒烟，避免长活尾。

## 6. 风险与判负 → PIVOT

已内置判负阈值（§2）。主要风险：控光语言不自明、数值让首小时太挫（→ 由垂直切片 M4 试人数据决定是否续）。若判负走 PIVOT：保留验证方法学/灯塔身份,转向更直觉语法（例改“点多久/范围”或给 1 个语义图标）再重跑。
