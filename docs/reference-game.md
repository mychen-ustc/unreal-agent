## 1. 参考游戏定位

参考游戏用于验证工具链能力的端到端载体。它本身不是产品，而是展示"这套 Agent 系统能做出什么"的落地 Demo 和压力测试。参考游戏做得越完整、越接近 3A 品质，就越能证明工具链的价值——这也是后续对外展示和商业化的最佳样板。

在对齐多 Agent 开发系统的需求上，参考游戏只承担以下验证职责：

- 端到端验证工具链从策略研究到打包发布的完整性与品质
- 作为评估组（E1–E6、UX 等）的批判对象和横向对标对象
- 为性能（§6）、里程碑（§7）与验收（§7）提供可度量的产出物

## 2. 品类选型依据（市场数据）

参考游戏的品类选择基于市场数据，以使其作为工具链验证载体具备行业说服力：

> 2025 年 Steam 平台数据显示，动作类和 RPG 类合计贡献了约 75% 的平台收入。黑暗奇幻（Dark Fantasy）子品类月收入超过 1 亿美元。PC 游戏市场连续多年创下新高，Steam 2025 年再次刷新同时在线和销售收入纪录。

据此选定的品类与规格见 [§3 参考游戏规格](#3-参考游戏规格)。

## 3. 参考游戏规格

| 维度 | 定稿 |
|---|---|
| 游戏品类 | 黑暗奇幻动作冒险（第三人称），融合轻量 RPG 成长要素 |
| 核心玩法 | 半开放线性关卡，探索→收集→解谜→战斗→成长 的循环。关卡由 PCG 程序化生成，关卡结构由 Level Designer Agent 设计 |
| 美术风格 | 风格化写实（Stylized Realism），PBR 管线，暗黑奇幻方向。色调偏冷、材质以风化石材/金属/苔藓为主，参考《战神》(2018) 和《地狱之刃》的视觉语言，但不过度追求照片级真实——降低 AI 资产生成的难度和成本 |
| 世界观 | 原创奇幻世界。一个曾经辉煌的文明被未知力量摧毁后，自然用几百年的时间 reclaim 了城市。玩家扮演一个探索者，在废墟中寻找真相。主题围绕"文明与自然的对抗"和"记忆的代价" |
| 游戏时长 | 主线 5–8 小时，3–4 个生物群系区域，每个区域 1–2 小时 |
| 对标作品 | 《战神》(2018) 的线性叙事节奏 + 《地狱之刃：塞娜的献祭》的沉浸氛围 + 《瘟疫传说：安魂曲》的团队规模参考 |

## 4. 参考游戏受众

参考游戏本身不是产品，但为了证明工具链有效，它的品质和可玩性必须过关，因此需要定义它的受众来定标准：

| 画像 | 描述 | 对验证工具链的意义 |
|---|---|---|
| 核心玩家 | 25–40 岁男性为主，PC 单机玩家，玩过《战神》《艾尔登法环》《巫师 3》 | 若这些挑剔的核心玩家认可参考游戏，说明工具链产出的品质达标 |
| 次要玩家 | 18–25 岁动作玩家 | 检验动作与战斗部分的质量 |

## 5. 参考游戏项目需求

> 以下为参考游戏（验证载体）的具体内容需求，供生产 Agent 落地与验收使用。工具链侧的通用能力（Toolset、编排、安全治理、评估回退）见 PRD §4.1。

### 5.1 PCG 场景生成

AI 驱动的程序化场景，覆盖至少 3 种生物群系。

| 子功能 | 说明 | 优先级 |
|---|---|---|
| 生物群系 PCG 图 | 森林、废墟、山地 3 种群系的完整 PCG Graph | P1 |
| 地形生成 | 基于 spline 的地形层权重，驱动群系边界 | P1 |
| 植被分布 | Surface Sampler + 属性过滤 + Mesh Spawner，支持密度/坡度约束 | P1 |
| 交互物放置 | 可收集品、机关、敌人生成点按规则放置 | P1 |
| 动态调整 | Agent 根据截图反馈迭代参数 | P2 |

### 5.2 核心玩法

支持探索、收集、解谜、战斗的玩法循环。

| 子功能 | 说明 | 优先级 |
|---|---|---|
| 角色控制 | 第三人称角色移动、跳跃、攀爬、交互 | P1 |
| 收集系统 | 可收集物品（符文石等），计数 + UI 反馈 | P1 |
| 机关解谜 | 触发器驱动的机关门、移动平台、压力板 | P1 |
| 战斗系统（轻量） | 近战攻击、闪避、敌人 AI（巡逻/追击/攻击） | P2 |
| 关卡状态机 | 关卡全局状态管理（未激活 → 进行中 → 完成） | P1 |

### 5.3 资产管线

| 子功能 | 说明 | 优先级 |
|---|---|---|
| 外部模型生成 | 通过外部 API 生成纹理/3D 网格/材质 | P3 |
| 自动导入 | ArtPipelineToolset 自动导入 + Nanite 配置 | P3 |
| 资产元数据 | 每条资产写入 `SourceAssetMetadata`（来源/prompt/模型版本/license） | P3 |
| 质量审查 | 评估 Skill（资产质检）检查：风格一致性、三角面数、内容安全 | P3 |

### 5.4 关卡设计与 Blockout

在 PCG 场景生成之前，先完成灰盒关卡设计，确保空间布局和玩家动线合理。

| 子功能 | 说明 | 优先级 |
|---|---|---|
| 玩家动线 | 定义 spawn → POI → 高潮 → 出口的路径节点与节奏曲线 | P1 |
| 空间分区 | 按功能划分区域（探索区/解谜区/战斗区），分配坐标范围 | P1 |
| Blockout 放置 | 用简单几何体标记关键结构位置（门、平台、建筑遗迹） | P1 |
| 约束输出 | 生成 Blockout JSON → 传递给 Scene/PCG Agent 作为生成约束 | P1 |

### 5.5 灯光与后处理

为 PCG 场景自动配置灯光和后期处理，达到风格指南定义的氛围。

| 子功能 | 说明 | 优先级 |
|---|---|---|
| 主光源 | 根据风格指南放置 Directional Light + Sky Light + Sky Atmosphere | P1 |
| 局部光源 | 在 POI 和路径节点放置点光源/聚光灯 | P1 |
| PostProcess | 配置 PostProcess Volume（色调映射/Bloom/Ambient Occlusion/曝光） | P1 |
| 氛围验证 | 截图回传 → 与风格指南参考图比对 → 迭代调整 | P2 |

### 5.6 音频

为场景和玩法添加环境音和交互音效。

| 子功能 | 说明 | 优先级 |
|---|---|---|
| 环境音 | 按生物群系放置 Ambient Sound（风/水/鸟鸣/虫鸣） | P2 |
| 交互 SFX | 收集品拾取音效、机关门开合音效、脚步声表面切换 | P2 |
| 音频配置 | Sound Cue + Attenuation 设置（距离衰减/空间化） | P2 |

### 5.7 UI/HUD

为可玩 Demo 提供基本的用户界面。

| 子功能 | 说明 | 优先级 |
|---|---|---|
| HUD | 收集品计数、关卡进度指示器 | P2 |
| 交互提示 | 动态提示（"按 E 收集"、"需要 4 个符文石开门"） | P2 |
| DataTable 绑定 | UI 数据源绑定 DataTable，支持热更新数值 | P2 |

### 5.8 性能剖析

自动检测关卡性能瓶颈并反馈超标区域。

| 子功能 | 说明 | 优先级 |
|---|---|---|
| GPU Profiler | 触发 GPU Profiler → 输出 draw call / shader 复杂度 / 三角面数 | P2 |
| CPU Profiler | 触发 CPU Profiler → 输出 Game Thread 耗时 / Tick 开销 | P2 |
| 超标报告 | 标记超过约束阈值（帧率/资产密度/draw call）的区域 | P2 |
| 反馈闭环 | 超标报告 → 回传 Scene/Lighting Agent 做针对性优化 | P2 |

## 8. 产品决策记录（参考游戏部分）

以下为参考游戏（验证载体）的选型决策及其依据，用于端到端验证工具链能力。其品类选择基于市场数据以确保验证结果有行业说服力。工具链本身的形态决策见 PRD 附录 A 第 1 项。

| # | 事项 | 决策 | 依据 |
|---|---|---|---|
| 1 | 参考游戏品类 | 黑暗奇幻动作冒险（第三人称） | Steam 2025 年动作+RPG 占收入 ~75%；黑暗奇幻月收入超 1 亿美元 |
| 2 | 参考游戏目标平台 | PC 首发（Steam + EGS），主机 P3 评估 | PC 游戏市场连续多年创纪录增长；Steam 2025 年再创新高 |
| 3 | 团队规模 | 3–5 人核心 + AI Agent | 与 AI Agent 替代人力的目标一致；参考《瘟疫传说》等中小团队高品质先例 |
| 4 | 美术风格 | 风格化写实（Stylized Realism），PBR 管线 | 降低 AI 资产生成难度；避免照片级写实的高成本；Quixel Megascans 可直接用于材质基底 |
| 5 | 参考游戏时长 | 5–8 小时主线 | 小团队合理范围；AI 生成 3–4 个生物群系的可控 scope |
| 6 | 多人/联机 | 参考游戏不做多人 | 单机叙事是主要验证方向；EOS 预留接口供未来扩展 |
| 7 | 本地化 | 参考游戏首发中文 + 英文 | 覆盖 Steam 最大两个语言市场（中文 ~30%，英文 ~35%） |
| 8 | 对标作品 | 《战神》(2018)、《地狱之刃》、《瘟疫传说：安魂曲》 | 均为线性/半开放动作冒险，验证了品类的可行性作为工具链压力测试的合适载体 |
