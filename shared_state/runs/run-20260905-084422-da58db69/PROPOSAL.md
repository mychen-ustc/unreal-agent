# 核心玩法提案（run_id: run-20260905-084422-da58db69）

> 方向：半开放的海洋-灯塔动作冒险：在文明的光被影潮吞没百年的废海，身为被灯塔放逐的灯夫潜入废城与海床，收集记着旧文明的灯语，逐塔点亮以改变潮汐与机关来打开下一个水域；敌人是畏光集群的影带怪，核心机制是控光（灯=武器+盾+导航）。

## 1. 市场(S1)

### 结论
黑暗奇幻动作冒险（dark fantasy action/adventure）下的“光控解谜+海洋废土探索”细分赛道。

### 要点
- 目标用户：偏爱魂like挑战与深海克苏鲁氛围的单机动作玩家。
- 核心吸引力：光既是武器/盾，又是解密与导航的唯一语言。
- 差异化钩子：废海沉城与灯塔逐级点亮带来的非线性探索欲。
- 战斗张力：影带怪畏光，迫使玩家在照亮与暴露间做风险抉择。
- 情绪记忆点：孤寂废海、被放逐者的叙事，契合黑色浪漫审美。
- 赛道空位：主流偏陆城或太空，海洋+控光机制尚属稀缺组合。

## 2. 竞品(S2)

### 结论
光控解谜+海洋废土黑暗奇幻的动作冒险细分赛道，在硬核魂与解谜探索之间尚无直接对标，存在明显市场空位。

### 要点
- 黑魂：证明黑暗探索+高难战斗成立；空位：光为攻防/解谜的唯一语法。
- 深海迷航：证明海洋荒原能承载探索叙事；空位：用控光而非氧气/科技驱动。
- 塞尔达：证明光解谜+开放架构能诱发好奇心；空位：将“灯塔点亮”设为世界解锁轴。

## 3. 玩法设计(S3)

### 结论
核心循环：秒级在光影中移动、格挡与攻击，分钟级驱散影带怪并点亮火种/灯塔以解谜和建立安全区，十分钟级解锁新航道与新机制，向废海沉城深处推进探索与成长。

### 要点
- First-hour 目标：玩家完成首座沉城灯塔的点亮，情绪从“黑暗压迫”转为“光明可控”，并解锁通往下一海域的航道。
- 可证伪最小验切口假设：新玩家第1小时内无文字教学，若能自主把影带怪引入光域击杀、并用光解除首个闸门谜题，则“光为唯一交互语法”成立。
- 判负标准：若该流程失败率高于30%，或需要显式UI/引导提示才能完成，说明控光语言不够直觉、核心张力未达预期。
- 验证工具：单场景“沉塔-灯塔”垂直切片，含3场强制影带怪战斗与1个光闸门谜题，记录首次尝试行为与卡点位置。

## 4. 创意方向(S6)

### 结论
光是废海仅存的语言，你以灯塔之名，与影潮逐字对译沉没的文明。

### 要点
- 概念钩子：影潮不是怪物，是文明忘记读光的回声；你收集灯语，便是替废海重述记忆。
- 核心意象：孤塔举灯，光刃切开墨色海面，影带如退潮般蜷缩成路。
- Tone 色板情绪方向：深渊蓝黑、冷白灯焰与锈金余晖，压迫中透出克制的希望。

## 5. 导演立项目标(Director)

目标：通过“沉塔—灯塔”单场景垂直切片，验证“黑暗奇幻动作冒险＋海洋废土＋光控解谜”的细分赛道成立——光既是武器/盾，又是解谜与导航的唯一语言，并以点亮灯塔作为世界解锁轴。

成功判据（引用玩法假设）：第1小时内，不提供文字教学/显式UI引导，新玩家能自主完成“3场强制影带怪战斗＋1个光闸门谜题”，点亮首座沉城灯塔并解锁下一海域航道；失败率≤30%，且不依赖显式UI/引导提示帮助才达成，否则判负。

玩法假设：上述通过即证明“秒级光影移动/格挡/攻击、分钟级驱散影带怪并点亮火种/灯塔建立安全区、十分钟级点亮灯塔解锁新航道”的核心循环成立，足以占据硬核魂like与海洋探索之间无直接对标的赛道空位。

## 6. 横向基准评估(E6)

受欢迎度分：72/100  
理由：黑暗奇幻+克苏鲁+魂like+海洋废土，对核心单机动作玩家有极强辨识度与第一眼吸引力，但氛围阴郁、机制偏硬、谜题抽象，注定是强黏性垂类而非大众爆款。

三个最强差异化 Axis：

1. **光作为唯一交互语法**  
   光同时承担武器/盾、解谜、导航和教学信号，整个游戏不再靠文字/UI“告诉你怎么玩”，而是靠“看懂光”来理解规则——这是最强的风格化记忆点。

2. **沉海灯塔网络 = 世界解锁轴**  
   地图不是靠主线门禁推进，而是靠“点亮灯塔”产生安全区、传送锚点、视野与航道解锁；玩家从黑暗中被引导向远方光束，形成极自然的探索欲望曲线。

3. **影带怪与光域的风险博弈**  
   敌人不只是一个“弱光”属性怪，而是围绕光域重写行为逻辑：玩家必须把怪拖入光区、制造处决窗口，同时要承担照射范围、暴露位置、光源资源消耗的实时风险，构成独特战斗张力。

综合裁决：**GO**  
为什么：这是一个低成本、可证伪的垂直切片——用“失效率≤30%且不依赖UI”的硬标准直接验证“光语言是否成立”，赛道差位清晰，值得先投这一步跑行为数据，而不是在没有数据前就否定或转向。
